# `/plugin` Implementation Plan — P1: REPL+CLI parity, Gray Index, official cron+gateway

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/plugin` (+`/plugins` alias) manages plugins in the REPL with full `gray plugin` CLI parity, backed by the existing `gray-pkg` backend, with gray-cron and gateway as the first official Gray Index entries.

**Architecture:** Zero new runtime machinery — wire existing `gray-pkg::ops` (install/list/remove/update) to a new REPL command + extended CLI enum (copying the `Acp` subcommand-dispatch pattern), add the missing `enabled` state, and ship two thin official surfaces (cron already exists; gateway is a sidecar front over existing `gray-gateway` fns). Sidecar protocol v1 untouched.

**Tech Stack:** Rust workspace (`gray`, `gray-pkg`, `gray-plugin`, `gray-cron`, `gray-gateway`); `cargo test`, existing fixture scripts.

**Spec:** design approved in chat 2026-09-06 (naming: **Gray Index** + **Pi Gallery (preview)**; official set: gray-cron + gateway, echo stays reference-only; steal-list: gray-pkg, sidecar transport, gray-cron store/parser, gray-gateway daemon/systemd/pairing, Acp dispatch pattern). No separate spec doc — rulings made from chat approval are provisional (see ledger).

## Global Constraints

- Feature branch + PR, never push/merge `main` unasked (`main` protected, `test` check required). Work on `feat/plugin-p1`.
- Reuse-first: no new transport, scheduler, or index protocol; steal `gray-pkg`, `gray-cron`, `gray-gateway`, `Acp` dispatch pattern.
- Frozen contracts: `not in index: {name} (try /plugin install <https-url>)` miss string (`crates/gray-pkg/src/index.rs:84`); sidecar protocol v1 wire; `lock.json` shape stays backward-compatible (all new fields `#[serde(default)]`).
- Copy rule: pi source labeled exactly `Pi Gallery (preview)`; gray source labeled `Gray Index`.
- Commit discipline: `git add` ONLY the files your task lists. Never `git add -A`, never push, never amend another task's commit.

```rust
fn complete_plugin_args(cmd: &str, arg_text: &str) -> Vec<(String, String)> {
    const SUBS: &[(&str, &str)] = &[
        ("list", "list installed plugins"),
        ("search", "search Gray Index and Pi Gallery (preview)"),
        ("install", "install a plugin"),
        ("remove", "remove a plugin"),
        ("update", "update plugins"),
        ("enable", "enable a plugin"),
        ("disable", "disable a plugin"),
        ("check", "run conformance checks on a plugin dir"),
    ];
    let f = arg_text.to_lowercase();
    SUBS.iter()
        .filter(|(s, _)| f.is_empty() || s.contains(f.as_str()))
        .map(|(s, d)| (format!("{cmd} {s}"), d.to_string()))
        .collect()
}
```
