# gray v0 Implementation Plan

> **For agentic workers:** Execute task-by-task. Each task is one agy one-shot
> prompt + human verification (`cargo test` + `cargo run`). Steps use checkbox syntax.

**Goal:** smallest complete agent harness: OpenAI-compatible streaming → ReAct
loop → 4 tools → JSONL sessions → localhost web chat.

**Architecture:** cargo workspace, 5 crates. Core is pure (injected traits);
provider/tools/session are leaves; the binary wires everything and serves the UI.

**Tech stack:** tokio, reqwest + eventsource-stream, axum, rust-embed, serde,
thiserror, async_trait. No other deps without explicit approval.

**Spec:** `docs/superpowers/specs/2026-08-24-gray-harness-design.md`
**Prompt:** `docs/system-prompt.md` (frozen)

## Global constraints

- Rust stable, workspace `resolver = "3"`; edition 2024
- Libraries: `thiserror` enums only, no `anyhow`; no `unwrap()` on runtime paths
- Every crate has tests; core tested with scripted FakeProvider (no network)
- Dep additions require stating justification in the task output

### Task 1: Workspace scaffold

- [ ] `cargo build` green; `cargo test` green (empty); commit

### Task 2: gray-core types + AgentEvent

**Files:** `crates/gray-core/src/{lib.rs,message.rs,event.rs}`

Produces: `Message{role}`, `ContentBlock::{Text,ToolUse{id,name,args},ToolResult{id,content,is_error}}`,
`ToolDef{name,description,parameters}`, `AgentEvent::{Start,TextDelta,ToolCallStart,ToolCallEnd,ToolResult,TurnEnd{stop_reason,usage}}` (serde-tagged),
`ChatRequest{system,messages,tools}`, `StreamEvent` provider-side enum.
Tests: serde round-trips.

### Task 3: gray-core loop

**Files:** `crates/gray-core/src/agent.rs`

Produces: `trait Provider { fn stream(&self, req: ChatRequest) -> BoxStream<Result<StreamEvent>> }`,
`trait ToolExecutor { fn execute(&self, ctx:&ToolContext, name:&str, args:Value) -> BoxFuture<ToolOutput> }`,
`Agent::run(msg)` driving until TurnEnd without tool calls. Tool errors → error ToolResult.
Tests: FakeProvider scripted multi-turn tool call, tool-error recovery, max-turns guard.

### Task 4: gray-provider (OpenAI-compatible SSE)

**Files:** `crates/gray-provider/src/{lib.rs,openai.rs,testutil.rs}`

Produces: `OpenAiProvider{base_url,api_key,model}`, SSE parse via eventsource-stream,
tool-call arg accumulation across chunks (keyed by index), parsed once at end,
retry 429/5xx ×3 backoff+jitter. Tests: wiremock recorded fixtures (chunked args case!).

### Task 5: gray-tools

**Files:** `crates/gray-tools/src/{lib.rs,bash.rs,read.rs,write.rs,edit.rs}`
Produces: async `Tool` trait w/ `is_concurrency_safe`, `ToolContext{cwd,cancel}`,
4 builtins. Truncation: 2000 lines/50KB head+tail; error cap 2KB. Bash: tokio process,
kill_on_drop, process_group(0), 60s timeout. Edit: exact-match replace or fail.
Tests: tmpdir-based for fs tools; sleep-command timeout test for bash.

### Task 6: gray-session

**Files:** `crates/gray-session/src/lib.rs`
Produces: `SessionStore` trait, `JsonlSessionStore` at `~/.gray/sessions/<id>.jsonl`;
header line {version,id,timestamp,cwd}; entries `{id,parentId,message}`.
Tests: round-trip, resume, coherent-partial-flush on abort.

### Task 7: gray binary — print mode

**Files:** `crates/gray/src/{main.rs,config.rs,print.rs}`
Produces: clap CLI `--print "prompt"`, `--model provider/model`, `--base-url`,
env keys (`OPENAI_API_KEY`, `GRAY_BASE_URL` default `https://openrouter.ai/api/v1`),
stdout delta printing, session written. Test: config precedence unit tests.

### Task 8: gray binary — axum web

**Files:** `crates/gray/src/web.rs`, `web/index.html`, `web/main.js`
Produces: `POST /api/chat` SSE of AgentEvents, `GET/DELETE /api/sessions[/:id]`,
static embed via rust-embed; index.html = composer + message list + streaming render,
vanilla JS ~250 lines total. Test: integration test hitting endpoints with FakeProvider.
